# Tutorial 6 — Dynamic Programming and Graph Traversal

## Core Concepts
Dynamic Programming (DP) is a method for solving complex problems by breaking them down into simpler subproblems. It is particularly useful for optimization problems and problems involving combinatorial structures. In this tutorial, we focus on subset problems, partitioning sets into equal subsets, counting subsets, and grid path problems.

### Key Concepts:
1. **Subset Sum Problem**: Given a set of integers, determine if there is a subset whose sum equals a given target.
2. **Partition Problem**: Determine if a set can be partitioned into two subsets with equal sum.
3. **Counting Subsets**: Count the number of subsets that sum to a specific value.
4. **Grid Paths**: Count the number of ways to reach a cell in a grid from the top-left corner to the bottom-right corner.

## Algorithms & Complexity

### 1. Subset Sum
**Recurrence Relation**:
- Let `dp[i][s]` be true if a subset of the first `i` elements can sum to `s`.
- The recurrence is:
  \[
  dp[i][s] = dp[i-1][s] \text{ OR } dp[i-1][s - A[i]] \quad \text{(if } s \geq A[i]\text{)}
  \]

**Complexity**:
- Time: \(O(nS)\), where \(n\) is the number of elements and \(S\) is the target sum.
- Space: \(O(nS)\).

### 2. Partition into Equal Subsets
**Steps**:
1. Check if the total sum of the set is even. If not, return false.
2. Reduce the problem to a subset sum problem with target \( \text{sum}/2 \).

**Complexity**:
- Time: \(O(nS)\)
- Space: \(O(nS)\)

### 3. Count Subsets
**Recurrence Relation**:
- Let `dp[i][s]` be the number of ways to form the sum `s` using the first `i` elements.
- The recurrence is:
  \[
  dp[i][s] = dp[i-1][s] + dp[i-1][s - A[i]] \quad \text{(if } s \geq A[i]\text{)}
  \]

**Complexity**:
- Time: \(O(nS)\)
- Space: \(O(nS)\)

### 4. Grid Paths
**Recurrence Relation**:
- Let `dp[i][j]` be the number of ways to reach cell `(i, j)`.
- The recurrence is:
  \[
  dp[i][j] = dp[i-1][j] + dp[i][j-1]
  \]
- Base cases: `dp[0][j] = 1` and `dp[i][0] = 1` for all valid `i` and `j`.

**Complexity**:
- Time: \(O(nm)\) for an \(n \times m\) grid.
- Space: \(O(nm)\).

## Theorems & Proofs
1. **Subset Sum Theorem**: If a subset exists that sums to a target, it can be found using the above DP approach.
2. **Partition Theorem**: A set can be partitioned into two equal subsets if and only if the total sum is even and a subset with sum equal to half the total exists.

## Worked Examples
### Example 1: Subset Sum
**Problem**: Given the set \(A = \{3, 34, 4, 12, 5, 2\}\) and target sum \(9\), determine if a subset exists that sums to \(9\).

**Solution**:
1. Initialize `dp` array of size \((n+1) \times (S+1)\).
2. Fill the `dp` table using the recurrence relation.
3. Check `dp[n][9]`.

### Example 2: Count Subsets
**Problem**: Count the number of subsets of \(A = \{1, 2, 3\}\) that sum to \(4\).

**Solution**:
1. Initialize `dp` array.
2. Use the counting recurrence relation.
3. The answer will be found in `dp[n][4]`.

## Common Mistakes to Avoid
1. **Ignoring Base Cases**: Always initialize base cases correctly in DP.
2. **Incorrect Recurrence Relations**: Ensure the recurrence accurately reflects the problem.
3. **Space Complexity**: Be mindful of space usage; consider optimizing to \(O(S)\) if possible.
4. **Off-by-One Errors**: Pay attention to array indexing, especially in DP tables.

## Graph Traversal — Supplement from Tutorial algo 6.pdf
### Breadth-First Search (BFS) — PDF pages 7–47
The supplied tutorial 6 slides also teach graphs and breadth-first search. BFS starts at a source with distance zero, places it in a FIFO queue, and discovers each previously unseen neighbor with distance one greater than the current vertex. Vertices are processed in nondecreasing distance from the source. Distances count edges in an unweighted graph. The discovery edges form a BFS tree; its levels are the shortest-path distances. For an undirected graph, an edge joins vertices on the same or adjacent BFS levels. With adjacency lists the traversal takes $O(|V|+|E|)$. Scanning every possible neighbor in an adjacency matrix can take $O(|V|^2)$.

### Multiple Sources and Search Trees — PDF pages 48–51; HW3_ALGO.pdf pages 1–2
To find unweighted distance from a set of sources, the tutorial adds a new source connected to every vertex in the set, runs BFS, and subtracts one from the computed distances. This construction preserves the intended edge-count metric.

The supplied HW3 explicitly assumes that BFS and depth-first search (DFS) have been taught in class. DFS explores along a branch before backtracking, whereas BFS explores by distance layers. The assignment asks about tree diameter, representation-dependent runtimes, and properties of the two search trees. These are covered graph-traversal prerequisites at this point; guide the student to reason about tree edges and cycles without supplying the assignment proofs.

### Directed Acyclic Graphs and Topological Ordering — PDF pages 55–70
A DAG is a directed graph with no directed cycle. A topological ordering puts the tail of every edge before its head. The slides give an indegree-based algorithm: initialize a queue of zero-indegree vertices, remove one, output it, and decrease the indegrees of its outgoing neighbors. Enqueue newly zero-indegree vertices. With adjacency lists, each vertex and edge is processed once, taking $O(|V|+|E|)$. If vertices remain when the queue empties, no topological ordering exists for the whole graph.

### Counting Paths in a DAG — PDF pages 87–95
After topologically sorting a DAG, initialize $ways(u)=1$ at the chosen start and zero elsewhere. Process vertices in topological order and add $ways(v)$ to the count of each outgoing neighbor. An edge only leads to a later vertex, so all contributions to a vertex are available before it is processed. The tutorial uses this combination of graph order and dynamic programming to count directed paths.

### Even-Length Paths and Layered Graphs — PDF pages 96–112
To enforce an even number of edges in an unweighted walk, duplicate each vertex into parity states. Every original edge switches parity. Run BFS from the even state of the source to the even state of a target. Returning to the even layer means an even edge count; BFS finds the smallest such count. Prove correspondence in both directions between original walks and paths in the state graph. A repeated original vertex can occur with different states, so do not silently claim that the projected walk must be simple.
