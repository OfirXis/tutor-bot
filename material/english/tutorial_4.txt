# Tutorial 4 — Dynamic Programming (DP)

## Core Concepts
Dynamic Programming (DP) is a method for solving complex problems by breaking them down into simpler subproblems. It is applicable when the problem exhibits two key properties:
1. **Overlapping Subproblems**: The problem can be broken down into subproblems that are reused multiple times.
2. **Optimal Substructure**: An optimal solution to the problem can be constructed from optimal solutions of its subproblems.

### Steps in Dynamic Programming
1. **Define the Subproblem**: Identify the smaller subproblems that can be solved independently.
2. **Recurrence Relation**: Establish a relationship between the solution of the problem and the solutions of its subproblems.
3. **Base Cases**: Define the simplest cases that can be solved directly.
4. **Order of Computation**: Determine the order in which the subproblems should be solved to ensure that each subproblem is solved before it is needed.
5. **Extract the Answer**: Use the computed values to derive the final solution to the original problem.

## Algorithms & Complexity

### 1. Fibonacci Sequence
- **Definition**: 
  - \( F(0) = 0 \)
  - \( F(1) = 1 \)
  - \( F(n) = F(n-1) + F(n-2) \) for \( n > 1 \)
  
- **Naive Recursive Implementation**:
  ```python
  def fib(n):
      if n < 2:
          return n
      return fib(n-1) + fib(n-2)
  ```
  - **Complexity**: \( O(2^n) \)

- **Dynamic Programming Implementation**:
  ```python
  def fib_dp(n):
      dp = [0] * (n + 1)
      dp[1] = 1
      for i in range(2, n + 1):
          dp[i] = dp[i-1] + dp[i-2]
      return dp[n]
  ```
  - **Complexity**: \( O(n) \) time, \( O(n) \) space

- **Optimized Space Implementation**:
  ```python
  def fib_optimized(n):
      a, b = 0, 1
      for _ in range(2, n + 1):
          a, b = b, a + b
      return b
  ```
  - **Complexity**: \( O(n) \) time, \( O(1) \) space

### 2. Rod Cutting
- **Problem Statement**: Given a rod of length \( n \) and a price list \( p[j] \) for lengths \( j \), determine the maximum revenue obtainable by cutting the rod and selling the pieces.
  
- **Recurrence Relation**:
  \[
  dp[i] = \max(p[j] + dp[i-j]) \quad \text{for } j = 1 \ldots i
  \]
  
- **Implementation**:
  ```python
  def rod_cutting(prices, n):
      dp = [0] * (n + 1)
      for i in range(1, n + 1):
          for j in range(1, i + 1):
              dp[i] = max(dp[i], prices[j-1] + dp[i-j])
      return dp[n]
  ```
  - **Complexity**: \( O(n^2) \)

### 3. Longest Common Subsequence (LCS)
- **Problem Statement**: Given two sequences, find the length of their longest subsequence present in both.
  
- **Recurrence Relation**:
  \[
  dp[i][j] = 
  \begin{cases} 
  dp[i-1][j-1] + 1 & \text{if } X[i] = Y[j] \\
  \max(dp[i-1][j], dp[i][j-1]) & \text{otherwise}
  \end{cases}
  \]
  
- **Implementation**:
  ```python
  def lcs(X, Y):
      m, n = len(X), len(Y)
      dp = [[0] * (n + 1) for _ in range(m + 1)]
      for i in range(1, m + 1):
          for j in range(1, n + 1):
              if X[i-1] == Y[j-1]:
                  dp[i][j] = dp[i-1][j-1] + 1
              else:
                  dp[i][j] = max(dp[i-1][j], dp[i][j-1])
      return dp[m][n]
  ```
  - **Complexity**: \( O(mn) \)

### 4. 0/1 Knapsack Problem
- **Problem Statement**: Given weights and values of \( n \) items, determine the maximum value that can be carried in a knapsack of capacity \( W \).
  
- **Recurrence Relation**:
  \[
  dp[i][w] = 
  \begin{cases} 
  dp[i-1][w] & \text{if } wt[i] > w \\
  \max(dp[i-1][w], dp[i-1][w-wt[i]] + val[i]) & \text{otherwise}
  \end{cases}
  \]
  
- **Implementation**:
  ```python
  def knapsack(weights, values, W):
      n = len(weights)
      dp = [[0] * (W + 1) for _ in range(n + 1)]
      for i in range(1, n + 1):
          for w in range(W + 1):
              if weights[i-1] <= w:
                  dp[i][w] = max(dp[i-1][w], dp[i-1][w-weights[i-1]] + values[i-1])
              else:
                  dp[i][w] = dp[i-1][w]
      return dp[n][W]
  ```
  - **Complexity**: \( O(nW) \)

## Theorems & Proofs
- **Optimal Substructure**: A problem exhibits optimal substructure if an optimal solution can be constructed from optimal solutions of its subproblems.
- **Overlapping Subproblems**: A problem has overlapping subproblems if it can be broken down into subproblems that are reused multiple times.

## Common Mistakes to Avoid
- **Ignoring Base Cases**: Always define base cases clearly; they are crucial for the correctness of the DP solution.
- **Incorrect Recurrence Relations**: Ensure that the recurrence relation accurately reflects the problem's requirements.
- **Space Complexity**: Be mindful of space usage; optimize where possible, especially in large problems.
- **Order of Computation**: Ensure that subproblems are solved in the correct order to avoid using uninitialized values.
